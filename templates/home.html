Architecture & Core Principles

Separation of Intelligence & Safe Execution

Gemini handles understanding and natural reasoning. Django handles state, session authentication, and database isolation. A dedicated Action Controller validates commands against an allowlist before execution.

1. Interface & Voice
User Input & STT

Browser captures voice through Web Speech API or typed input, securely delivering requests with CSRF protection to Django.

2. Reasoning Engine
Gemini LLM Processing

Google Gemini interprets user intent, incorporates personalized memory, and generates conversational answers or structured action payloads.

3. Protected Actions
Allowlist Validation

The action controller blocks arbitrary OS/code execution, validates reminder dates, verifies ownership, and triggers voice feedback.
